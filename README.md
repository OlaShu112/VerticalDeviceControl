# How to Clone and Run the Project

## 1. Open PowerShell or Git Bash

Open a terminal on your computer.

## 2. Navigate to the Directory Where You Want to Store the Project

Example (XAMPP directory):

```
cd C:\xampp\htdocs
```

You may choose any other directory if preferred.

## 3. Clone the Repository

Run the following command:

```
git clone https://github.com/OlaShu112/VerticalDeviceControl.git
```

This will download the project into a folder named **VerticalDeviceControl**.

## 4. Navigate into the Project Folder

```
cd VerticalDeviceControl
```

## 5. Open the Project

Open the folder in **Visual Studio Code**.

## 6. Build and Run the Project

1. Ensure the **PlatformIO extension** is installed in Visual Studio Code.
2. Open the project folder.
3. Use PlatformIO to **build and upload** the project according to the configuration in `platformio.ini`.
